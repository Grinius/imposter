# Product brief

## Confirmed user intent

- Build an online imposter game with high-quality graphics.
- Build for Google search discovery and potential ongoing income.
- The user reports high-volume, low-competition keywords and will provide the data later. These metrics have not been independently verified.
- Current request: build the initial playable version; keyword data will come later.

## Proposed product direction

A secret-word social deduction game: everyone receives the same word except the imposter; players give clues, discuss, and vote. Proposed first release includes pass-one-phone play and private online rooms. The assistant suggested a softly lit tabletop, illustrated suspects, tactile cards, and dramatic reveals. The initial implementation uses this direction as a reversible design choice; branding remains open.

Proposed flow: setup → private reveals → clue rounds → discussion → voting → result → replay. Support curated categories and optional hints. Decide exact rules (ties, final guesses, multiple imposters, player limits) explicitly before implementation.

The main page should make playing immediately obvious. Instructions and useful content should support gameplay. Design for phones first and enrich larger screens.

## Commercial assumptions to validate

Candidate monetization: restrained between-round ads, ad removal, optional packs. No pricing or revenue forecast is approved. Shared-device play produces fewer sessions than player counts imply. Multiplayer needs hosting and maintenance; revenue is not guaranteed to be passive.

## Open decisions

Keyword export and target country/language; brand and domain; final art direction; gameplay variants; deployment provider and operating budget; monetization timing. These do not prevent a reversible local prototype.
